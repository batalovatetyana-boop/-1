# Практична робота № 2

## Моделювання радіоактивного розпаду. Вимірювання радіаційного фону

**Мета:** на моделі з монетами переконатися, що за однаковий час розпадається однакова частка ядер; побудувати графік розпаду; навчитися вимірювати радіаційний фон дозиметром.

**Тривалість:** 35–40 хвилин.

1. [Експериментальна робота № 8. Моделювання радіоактивного розпаду](https://www.youtube.com/watch?v=k7VkfsD-F6I)
2. [Лабораторна робота «Моделювання радіоактивного розпаду»](https://www.youtube.com/watch?v=YHUBMd3EZ5g)

Якщо монет немає, можна скористатися онлайн-симулятором: <https://zelenskiy.github.io/PhysLabs/coins.html>

### Ідея моделі

- Кожна монета — радіоактивне ядро.
- Один «кидок» — один проміжок часу.
- Монета, що впала **гербом** догори, — ядро **розпалося**, її прибираємо.
- Монета, що впала **числом** догори, — ядро ще **не розпалося**, її кидаємо знову.

Ймовірність «гербу» — 1/2, тому в цій моделі період піврозпаду дорівнює одному кидку.

### Обладнання

- 60–100 однакових монет (або картонних кружечків, позначених з одного боку);
- коробка чи лоток для кидання;
- аркуш у клітинку для графіка;
- дозиметр (якщо є в школі) — для частини 2.

### Хід роботи

**Частина 1. Моделювання розпаду (≈ 25 хв)**

1. Порахуйте монети — це N₀. Запишіть у таблицю.
2. Струсіть монети в коробці й висипте на стіл. Приберіть ті, що впали гербом догори.
3. Порахуйте монети, що залишилися, і запишіть.
4. Повторюйте кроки 2–3, поки не залишиться 1–2 монети (зазвичай 6–7 кидків).
5. Заповніть стовпчик «теоретично»: N₀ : 2, N₀ : 4, N₀ : 8 і так далі.
6. Побудуйте графік: по горизонталі — номер кидка, по вертикалі — кількість монет. Нанесіть на нього і дослідні, і теоретичні точки.

|---|---|---|---|---|---|---|---|---|
| Залишилось монет (дослід) | | | | | | | | |
| Теоретично N₀ : 2ⁿ | | | | | | | | |

**Частина 2. Вимірювання радіаційного фону (≈ 10 хв, за наявності дозиметра)**

1. Увімкніть дозиметр і зачекайте, поки покази стабілізуються (1–2 хв).
2. Виміряйте потужність дози в класі, біля вікна і в коридорі. Результати в мкЗв/год запишіть у таблицю.
3. Порівняйте з нормою природного фону (приблизно 0,1–0,2 мкЗв/год).

### Висновки (дайте відповіді письмово)

1. Яка частка монет «розпадалася» за кожен кидок?
2. Чому дослідні точки не точно збігаються з теоретичними?
3. Як зміниться результат, якщо взяти не 100, а 10 000 монет?
4. Чи можна передбачити, яка саме монета «розпадеться» наступною? Що це означає для справжніх ядер?
5. Чи відповідає виміряний фон нормі?

---

### Для вчителя: очікувані відповіді

1. Приблизно половина монет при кожному кидку.
2. Розпад — випадковий процес. Для малої кількості «ядер» відхилення великі.
3. Дослідні точки будуть значно ближчими до теоретичних: закон розпаду статистичний і точніше виконується для великої кількості ядер.
4. Ні. Так само неможливо передбачити, коли розпадеться конкретне ядро; закон описує лише поведінку великої кількості ядер.
5. Зазвичай так: 0,1–0,2 мкЗв/год (до 0,3 мкЗв/год вважається нормальним).

Варіант з кубиками: «розпалися» кубики, на яких випала шістка. Тоді за кидок розпадається 1/6, а період піврозпаду — приблизно 3,8 кидка. Цей варіант цікаво порівняти з монетами: у різних ізотопів різний T½.
